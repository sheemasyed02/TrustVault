# TrustVault frontend

Next.js App Router + TypeScript + Tailwind CSS scaffold.

Authentication and document pages are not implemented yet. The home route is a professional landing/login entry shell only.

## Setup

```bash
cd frontend
copy .env.example .env.local
npm install
```

## Run

```bash
npm run dev
```

Open http://localhost:3000

## Lint and build

```bash
npm run lint
npm run build
```
